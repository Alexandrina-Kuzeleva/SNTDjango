Веб-приложение для автоматизации работы садоводческого некоммерческого товарищества (СНТ). Управление новостями, документами, учёт взносов и личные кабинеты жителей.

## Функционал

### Для жителей:
- Регистрация и вход по номеру участка
- Личный кабинет с историей задолженностей
- Просмотр новостей и объявлений
- Просмотр документов СНТ
- Просмотр задолженностей по членским и целевым взносам

### Для модераторов:
- CRUD управление новостями
- Загрузка и удаление документов
- Загрузка Excel с долгами (автоматический парсинг)
- Сводка по задолженностям жителей

### Для администратора:
- Управление пользователями и правами
- Редактирование статических страниц
- Настройка контактной информации
-  Управление правлением СНТ
